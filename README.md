# 인생 한 턴 — Life Turn Sim

한 달에 한 번, 인생을 한 칸씩. 선택이 쌓여 인생이 되는 모바일 웹 턴제 시뮬레이션 **「인생 한 턴」**입니다.
이벤트 **2,259개**로 1세부터 80세까지 960개월을 거의 매달 새 사건으로 채웁니다. 유아기의 씨앗이 초·중·고·대학·사회·가정·중년·노년까지 **플래그로 이어지는 장기 인과 체인**과, 같은 나이에도 다른 풀이 열리는 **다분기 이벤트**를 갖췄습니다.
아이폰 사파리(390×844) 기준으로 만들었고, 빌드 도구 없이 정적 파일만으로 동작합니다.

## 플레이 방식

1. 시작 나이 7개 중 하나를 고릅니다.
   `1세(출산)` · `8세(초등학교 입학)` · `14세(중학교 입학)` · `17세(고등학교 입학)` · `20세(대학교 입학)` · `25세(취직)` · `35세(결혼)`
   아래 **출발 시나리오**(한국 현실 · 90년대생 · 재벌가 막내 · 흙수저)를 고르고, 전당에 내 기록이 있으면 **가문 이어받기**로 이전 인생의 재산·재능을 물려받아 시작할 수 있습니다.
2. `[인생 시작하기]`를 누르면 **1개월 단위** 턴이 시작됩니다. 표기는 `1세 · 1개월차` ~ `1세 · 12개월차`.
3. 이벤트 카드에서 2~4개의 선택지 중 하나를 고르면 **결과 스토리 + 스탯 변화**가 즉시 표시됩니다.
4. `[다음 1개월 진행하기 →]`를 누르면 한 달이 지나고, 12개월차 다음은 `2세 · 1개월차`가 됩니다.
   결과 화면에는 **5초 카운트다운**이 함께 돌아, 손대지 않아도 다음 턴으로 넘어갑니다(아래 「5초 자동 넘김」).
5. 하단 `📖 인생 일지`에서 지나온 선택을 시간순으로 다시 볼 수 있고, `인생 요약`에서 언제든 칭호가 붙은 요약 카드를 볼 수 있습니다.
6. 80세가 지나면 엔딩(인생 요약)이 나옵니다.

## 5초 자동 넘김

선택을 마치면 결과 카드 아래에 `⏱ 5초 후 다음 턴` 칩과 `⏸ 일시정지` 토글이 뜨고, 1초 단위로 줄어들다가 5초 뒤 자동으로 다음 달로 넘어갑니다.

- **빨리 넘기기**: `[다음 1개월 진행하기 →]` 버튼은 타이머를 즉시 해제하고 바로 넘깁니다.
- **천천히 읽기**: `⏸ 일시정지`를 누르면 남은 초를 붙잡아 두고 멈춥니다. `▶ 다시 시작`을 누르면 남은 시간부터 이어집니다.
  정지 상태는 `localStorage`(`lifeTurnSim.autoPaused`)에 남아, 새로고침해도 결과를 다 읽을 때까지 자동으로 넘어가지 않습니다.
- **멈춰야 하는 화면**: 졸업 결산·80세 엔딩으로 넘어가는 턴에서는 카운트다운 대신 `🎓 다음은 졸업 결산` / `🌅 다음은 인생 마무리` 안내만 띄우고 자동으로 넘기지 않습니다.
- **타이머 정리**: `새로 시작` · `전당` · `인생 일지` · `인생 요약` · `제안·제보`를 열거나, 되돌리기·다시 뽑기·긴급 회복을 쓰거나, 탭이 백그라운드로 가면 타이머를 끕니다(돌아왔을 때 모르는 사이 넘어가 있지 않게).
- **미니 승부 중에는 없음**: 승부가 끝나 결과가 뜨는 순간부터 카운트다운이 시작됩니다.

  **미션 이름은 지금 나이로 적습니다**(2026-11-24 전수조사). 26~49세·50~64세는 한 나이대가 두 개의 10년을
  걸치는데, 나이대 이름을 그대로 쓰면 **26~27세에게 `30·40대 미션`, 60세에게 `50대 미션`**이 떴습니다(제보).
  미션 id·목표는 나이대 그대로 두고 화면 이름만 나이에 맞춰 계산합니다(`missionLabelOf`).

  목표를 넘는 순간 카드가 한 번 번쩍이고 `🎯 … 미션 달성!` 토스트와 보너스가 붙습니다.
  한 인생에서 같은 나이대 미션은 **한 번만** 받습니다(`state.missions`).
- **출발선(base)은 그 나이대에 들어설 때의 값**: 진행률은 `(지금값 − base) / (목표 − base)`이고,
  `base = 출발선 − 0.35/0.65 × (목표 − 출발선)` 입니다. 그래서 **어느 나이로 시작해도, 1세부터 이어서 와도 막대가 늘 35%에서 출발**하고,
  그 구간에서 실제로 능력치를 쌓아야 100%가 됩니다(출발선은 `state.missionBase[나이대]`에 한 번만 적고, 저장본에도 남습니다).
  예전에는 목표가 절대값이라 20대 매력 60→70 은 시작부터 86%, 35세 재산 9,500만→3,000만 은 시작하자마자 달성이었습니다.
- **목표는 그 구간에서 실제로 오르는 폭**: 나이대마다 `gain`(바라는 성장폭)이 있고, 목표는 `출발선 + gain` 입니다.
  능력치에는 실제 천장(`ceil` — 88을 넘으면 최고치 유지 규칙이 눌러 내립니다)이 있어, 목표가 천장을 넘지 않게 자릅니다.
  그래서 10대·20대처럼 이미 높은 능력치는 큰 폭을, 50대·노년처럼 천장에 가까운 능력치는 작은 폭(+8~12)을 요구합니다.
  천장을 **이미 넘긴** 능력치로 나이대에 들어서면 그 목표는 이미 이룬 것으로 보고 시작부터 `달성 ✓`로 표시합니다.
  미션 정의가 재산(`asset`)을 가리키면 빚일 때 목표가 `빚 청산`으로 바뀌고 오른쪽에 지금 빚(`-4천만원`)을 보여 줍니다(지금 일곱 나이대는 모두 능력치를 씁니다).
- **왜 30·40대는 재산이 아니라 역량인가**: 성인 구간 사건의 재산 효과는 선택 한 번당 평균 마이너스라(2026-11-24 실측: 가정 −36만·중년 −68만원),
  재산 목표는 모아도 닿지 않습니다. 그 구간 사건(커리어)과 맞는 **역량**을 목표로 삼았고, 50대·노년은 **체력**입니다.
  (재산 자체는 아래 살림 장부로 매년 연봉이 들어와 더 이상 마이너스로만 흐르지 않습니다.)
- **스탯 팝업**: 선택으로 능력치나 재산이 바뀌면 해당 능력치 카드 바로 위에서 `+5` · `-15만` 배지가 떠올랐다 사라집니다.
  `position: absolute`라 능력치 줄 배치는 흔들리지 않고, 미션 보너스는 0.4초 뒤 한 칸 위에 따로 뜹니다.
- **붙박이 배치**: 아바타 카드는 사건 카드와 함께 스크롤되되 위쪽에 **sticky**로 붙어 있어, 결과를 읽으려고 스크롤해도 지금 표정과 미션 진행률이 계속 보입니다.
- **생애 진행도는 하단 도크 위**: `🍼 유아기 ─── 1 / 80세` 막대는 이벤트 카드 안(되돌리기 줄 위)이 아니라 **하단 `인생 일지 | 다음 1개월 진행하기` 줄 바로 위**에 붙박이로 있습니다(`#lifeBar`). 스크롤 영역(`#stage`) 밖의 flex 줄이라 카드가 짧든 길든 늘 같은 자리에 있고, 스폰서 배너가 떠 있으면 `배너 → 진행도 → 액션 버튼` 순서로 배너와 도크 사이에 들어갑니다. 진행도 줄과 버튼 줄은 경계선을 지워 한 덩어리 도크로 보이게 했습니다.
  짧은 화면(높이 720px 이하, 390×664 등)에서는 카드를 더 납작하게(약 58px) 줄여 사건 카드·선택지가 덜 밀리게 했습니다.

## 🩺 건강 위기 · 조기 엔딩 (2026-11-24)

예전에는 체력이 0이 되어도 80세까지 살았습니다. 이제는 위험한 몸이 이어지면 **건강 악화 조기 엔딩**으로 인생이 일찍 끝납니다. 다만 억울한 즉사가 아니게, 경고를 먼저 주고 대처할 선택지를 먼저 내밉니다.

## ☁️ 구글 로그인 · 클라우드 동기화 (선택)

**로그인 없이 그대로 노는 게 기본**입니다. 구글 로그인은 기기를 바꿔도 이어서 하고 싶을 때만 쓰는 선택 기능이고, 로그인하지 않으면 네트워크 요청이 **0건**입니다.

- **진입**: 시작 화면 `인생 시작하기` 아래 `G Google로 로그인` 칩(안내줄 `로그인하면 기기 간에 이어집니다 (선택)`) · 명예의 전당 제목 아래 같은 줄. 로그인하면 `☁️ 동기화됨 · 이름` + `로그아웃`으로 바뀝니다. (`SHOW_APPLE_SIGNIN` 을 켜면 `Apple로 로그인` 칩이 옆에 함께 뜹니다.)
- **회원탈퇴**: 로그인 상태의 명예의 전당에 `계정 및 클라우드 기록 삭제` — 위 「🍎 App Store 출시 준비」 참고.
- **무엇이 이어지나**: 진행 중 인생(`lifeTurnSim.save.v1`) · 명예의 전당(`lifeTurnSim.hall.v1`, 🧬 카메오 인물의 근거) · 칭호 도감(`lifeTurnSim.titles.v1`). 화면 설정(자동 넘김·배너 접기)과 제보 게시판의 기기별 제한은 기기에 남깁니다.
- **합치기(merge) 규칙** — 잃지 않는 쪽으로
  - 전당: `id` 기준 합집합(같은 기록은 한 번), 내 기록은 최근 240건까지
  - 칭호: `id` 기준 합집합, 같은 칭호는 **먼저 딴 기록**을 남김
  - 진행 중 인생: 마지막으로 저장한 쪽(`updatedAt`). 단 **지금 이 화면에서 플레이 중이면 이 기기의 인생**이 이깁니다(플레이 도중 남의 기록으로 갈아치우지 않게).
  - 다른 기기에서 `새로 시작`을 누르면 그 사실(`saveAt`)도 올라가 저장본이 되살아나지 않습니다.
- **로그인 방식**: Supabase GoTrue OAuth(**PKCE S256**) — 외부 스크립트 없이 `fetch`로만. `code_verifier`는 `localStorage`(`lifeTurnSim.auth.pkce.v1`)에 두고 돌아온 `?code=`를 토큰으로 바꿉니다. 토큰 만료 60초 전에 자동 갱신하고, 401이면 한 번 갱신해 재시도합니다.
  - **갱신은 한 번만**(`refreshInflight`) — 시작 화면·전당·화면 복귀가 같은 순간에 만료된 토큰을 갱신하려 해도 리프레시 요청은 하나입니다. GoTrue 는 리프레시 토큰을 회전시키므로 두 번째 요청이 400(`Already Used`)으로 거절당하기 때문입니다. 그 사이 다른 탭이 새 세션을 저장했다면 그 토큰으로 이어 갑니다.
  - **만료 정리**: GoTrue 는 무효한 리프레시 토큰에 401 이 아니라 **400**(`validation_failed`)으로 답합니다. 400/401 로 거절되면 이 기기의 로그인 세션만 지우고(`expireSession`) 칩을 `G Google로 로그인` + `로그인이 만료됐어요 · 다시 로그인해 주세요`로 되돌립니다. 게임 기록(진행·전당·칭호)은 지우지 않으며, 이후 다시 시도해도 죽은 토큰으로 요청하지 않습니다.
  - 앱이 백그라운드로 내려가는 순간(`visibilitychange` hidden)에는 토큰 갱신을 **시작하지 않습니다** — iOS 가 페이지를 재우면 회전된 토큰을 받지 못해 세션이 죽습니다.
- **저장**: Supabase `public.life_sim_user_state`(사람 1명당 1행, 사용자당 2MB 제한) — 스키마·RLS·RPC는 `supabase/life_sim_cloud_sync.sql`(다시 실행해도 안전).
  - RLS: `auth.uid() = user_id` 인 본인 행만 `select`/`insert`/`update`/`delete`, **anon 은 권한 없음**
  - 저장은 `life_sim_put_state(p_data jsonb, p_revised_at bigint)` **security definer** RPC 하나로. 들어온 `revised_at` 이 저장된 것보다 과거면 덮어쓰지 않고 지금 상태를 돌려주고, 앱은 돌려받은 값이 다르면 한 번 더 합쳐 올립니다(여러 기기가 동시에 저장해도 최신이 남게).
  - Supabase Auth 의 Google 제공자와 리다이렉트 주소(`https://life-turn-sim.vercel.app/**`)는 대시보드에서 설정되어 있습니다(릴스핀과 같은 프로젝트 공용).
    로컬(`python3 -m http.server`)에서 진짜 구글 로그인까지 보려면 Authentication → URL Configuration 의 Redirect URLs 에 `http://localhost:포트/**` 를 한 줄 추가해야 합니다.
- **실패해도 로컬은 그대로**: 네트워크가 끊기면 칩이 `동기화 실패 · 다시 시도`로 바뀌고 저장본은 건드리지 않습니다. 아이폰에서는 `title` 툴팁이 보이지 않으므로 **칩 아래에 실제 사유를 42자로 줄여 글자로** 남깁니다(`.sync-why`). 탭을 숨기거나 다시 열 때도 한 번 맞춥니다.
- **저장은 한 번에**: 서버는 `jsonb` 라 키 순서를 바꿔 돌려주므로, 돌려받은 값이 같은지 볼 때 키를 정렬해 비교합니다(순서만 달라 두 번 올리던 것을 막음).
- **전체 랭킹은 따로**: 동기화되는 전당 전체가 아니라, 랭킹에 올린 기록만 별도 테이블(`public.life_sim_leaderboard`)에 공개됩니다
  (스키마·RPC: `supabase/life_sim_leaderboard.sql`). 무엇이 공개되는지는 위 「전체 유저 익명 랭킹」과 개인정보처리방침 1·5항에 적었습니다.

### 역량·행운 규칙 (2026-11-18 추가)

## 이벤트 추가하기

생애주기 모듈(`assets/events/*.js`)에 `X(...)` 한 줄로 추가하면 엔진이 자동으로 집어 갑니다.

```js
// X(stage, id, 나이(또는 [최소,최대]), 장소, 제목, 상황, 선택지[, 옵션])
X('work', 'my_event', [28, 30], '회의실', '제목', '상황 설명', [
  ['선택지 A', '결과 스토리', { mental: 2, asset: -1 }],          // 효과
  ['선택지 B', '결과 스토리', { social: 2 }, { 야근러: true }]     // 효과 + 플래그
]);

// 마일스톤(특정 나이·개월차 고정) 예
X('work', 'my_milestone', 28, '은행', '청약통장', '설명', [
  ['가입한다', '결과', { asset: -1 }],
  ['미룬다', '결과', { mental: 1 }]
], { at: [28, 4], milestone: true });

// 조건 분기 예 — 앞선 선택(플래그)이 있어야만 열리고, 스탯에 따라 확률이 달라진다
X('work', 'my_branch', [27, 34], '작업실', '작업실 임대', '설명', [
  ['얻는다', '결과', { mental: 3, asset: -300 }, { 작품활동: true }],
  ['집에서 계속한다', '결과', { mental: 1 }]
], { requireFlags: '예술가_길', minStat: { mental: 45 }, weight: function (s) { return s.flags.전시회 ? 4 : 2; } });

// 인생의 갈림길 — 같은 달의 다른 마일스톤보다 먼저 제시된다
X('college', 'my_fork', 20, '운동장', '동아리 선택', '설명', [
  ['가입한다', '결과', { hp: 3 }, { 축구부: true }],
  ['관중으로 남는다', '결과', { social: 2 }]
], { at: [20, 4], milestone: true, fork: true });
```
