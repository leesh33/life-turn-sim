# 인생 한 턴 — Life Turn Sim

한 달에 한 번, 인생을 한 칸씩. 선택이 쌓여 인생이 되는 모바일 웹 턴제 시뮬레이션 **「인생 한 턴」**입니다.
이벤트 **2,099개**로 1세부터 80세까지 960개월을 거의 매달 새 사건으로 채웁니다. 유아기의 씨앗이 초·중·고·대학·사회·가정·중년·노년까지 **플래그로 이어지는 장기 인과 체인**과, 같은 나이에도 다른 풀이 열리는 **다분기 이벤트**를 갖췄습니다.
아이폰 사파리(390×844) 기준으로 만들었고, 빌드 도구 없이 정적 파일만으로 동작합니다.

- 실서버: **https://life-turn-sim.vercel.app** (Vercel 프로젝트 `life-turn-sim`, 팀 leesh33)
- 저장소: https://github.com/leesh33/life-turn-sim
- 별도 백엔드 없음 · 진행 상황은 브라우저 `localStorage`에 자동 저장

## 플레이 방식

1. 시작 나이 7개 중 하나를 고릅니다.
   `1세(출산)` · `8세(초등학교 입학)` · `14세(중학교 입학)` · `17세(고등학교 입학)` · `20세(대학교 입학)` · `25세(취직)` · `35세(결혼)`
2. `[인생 시작하기]`를 누르면 **1개월 단위** 턴이 시작됩니다. 표기는 `1세 · 1개월차` ~ `1세 · 12개월차`.
3. 이벤트 카드에서 2~4개의 선택지 중 하나를 고르면 **결과 스토리 + 스탯 변화**가 즉시 표시됩니다.
4. `[다음 1개월 진행하기 →]`를 누르면 한 달이 지나고, 12개월차 다음은 `2세 · 1개월차`가 됩니다.
   결과 화면에는 **5초 카운트다운**이 함께 돌아, 손대지 않아도 다음 턴으로 넘어갑니다(아래 「5초 자동 넘김」).
5. 하단 `📖 인생 일지`에서 지나온 선택을 시간순으로 다시 볼 수 있고, `인생 요약`에서 언제든 칭호가 붙은 요약 카드를 볼 수 있습니다.
6. 80세가 지나면 엔딩(인생 요약)이 나옵니다.

## 5초 자동 넘김

선택을 마치면 결과 카드 아래에 `⏱ 5초 후 다음 턴` 칩과 `⏸ 일시정지` 토글이 뜨고, 1초 단위로 줄어들다가 5초 뒤 자동으로 다음 달로 넘어갑니다.

- **빨리 넘기기**: `[다음 1개월 진행하기 →]` 버튼은 타이머를 즉시 해제하고 바로 넘깁니다.
- **천천히 읽기**: `⏸ 일시정지`를 누르면 남은 초를 붙잡아 두고 멈춥니다. `▶ 다시 시작`을 누르면 남은 시간부터 이어집니다.
  정지 상태는 `localStorage`(`lifeTurnSim.autoPaused`)에 남아, 새로고침해도 결과를 다 읽을 때까지 자동으로 넘어가지 않습니다.
- **멈춰야 하는 화면**: 졸업 결산·80세 엔딩으로 넘어가는 턴에서는 카운트다운 대신 `🎓 다음은 졸업 결산` / `🌅 다음은 인생 마무리` 안내만 띄우고 자동으로 넘기지 않습니다.
- **타이머 정리**: `새로 시작` · `전당` · `인생 일지` · `인생 요약` · `제안·제보`를 열거나, 되돌리기·다시 뽑기·긴급 회복을 쓰거나, 탭이 백그라운드로 가면 타이머를 끕니다(돌아왔을 때 모르는 사이 넘어가 있지 않게).
- **미니 승부 중에는 없음**: 승부가 끝나 결과가 뜨는 순간부터 카운트다운이 시작됩니다.

## 🏅 칭호·인연 도감 (유년·학창기)

1~19세에만 열리는 숨은 칭호 **20종**입니다. 특정 선택(플래그)과 스탯이 맞물릴 때 해금되고, 해금 순간 상단에 배지 팝업이 뜹니다(누르면 도감으로).

- 예: `🍼 조리원 우량아`(우렁찬 아기) · `🍚 급식실 1등`(대식가 + 체력 60 이상, 7~13세) · `👑 골목대장` · `📖 책벌레` · `⚽ 운동장 축구왕` · `💌 첫사랑` · `🌙 암산 천재`(숫자 씨앗 + 멘탈 65 이상)
- 칭호 16종 + 인연 4종(골목대장·동물의 친구·단짝·첫사랑). 20종 모두 실제 이벤트 플래그로 도달할 수 있습니다.
- 해금 기록은 `localStorage`(`lifeTurnSim.titles.v1`)에 **판과 무관하게 누적**됩니다. 새 인생을 시작해도 도감은 남습니다.
- **도감 여는 곳**: 시작 화면 상단 `🏅 칭호 도감`, 명예의 전당 상단 `🏅 칭호·인연 도감` 카드, 해금 배지 팝업.
- 도감은 `12 / 20 수집 · 60%` 진행 막대와, 잠긴 칭호의 해금 나이대(`7~13세에 해금`)를 보여 줍니다.

## ⚡ 5~10초 미니 승부 (전 연령 · 45개 이벤트)

유년(6~7세)부터 노년(80세)까지, 장면에 맞는 짧은 승부가 붙습니다. 한 번에 하나씩, 누르면 5~10초 안에 승/패가 갈립니다.

| 승부 | 방식 | 주로 나오는 곳 |
| --- | --- | --- |
| 🎲 주사위 | 두 개를 굴려 합을 겨룹니다. 동점이면 한 번 더 | 딱지치기·청소 당번·동호회 내기 |
| ✌️ 가위바위보 | 손을 고르면 상대가 즉시 냅니다. 비기면 다시 (3번 비기면 패) | 소개팅·반장 단일화·손주 놀이 |
| 🎯 타이밍 | 좌우로 움직이는 막대를 초록 구간에서 멈춥니다 | 면접·계주 바통·자유투·횡단보도 |
| 🪙 동전 | 앞/뒤 중 하나를 고르고 0.8초 플립 애니메이션 뒤 결과 | 유치원 문 앞·뽑기·시장 덤 |
| 🃏 하이로우 | 공개된 카드(1~13)보다 다음 카드가 높을지 낮을지 | 할머니 집·기숙사·경로당 |
| 🧮 암산 | 사칙연산 3지선다, **7초** 제한 | 받아쓰기 눈썰미·야간 계산·장보기·장기 |

- **제한 시간**: 기본 10초, 암산만 7초. 시간이 다 지나면 패배로 처리됩니다.
- 승/패에 따라 결과 문구·스탯·플래그가 갈립니다(예: 면접 승리 → `취업_성공`, 소개팅 승리 → `인연_시작`).
- 승부 중에는 자동 넘김 타이머가 없고, **결과 화면부터 5초 카운트다운**이 돕니다.
- 선택지 정의는 `choice.mini = { type, title, desc, win:{result,effects,set}, lose:{...} }`, 엔진은 `Life.choose(s, i, { miniWin })`로 승패를 받아 적용합니다.
- 검증: `python3 scripts/verify_minigames.py --serve life-sim-web` — 390×844에서 6종을 모두 열어 보고 결과·카운트다운·가로 넘침·콘솔 오류를 확인합니다.

## 💰 재테크 · 가족 카드 (직장·가정기 25~50세)

돈이 갈래를 만들고, 그 갈래가 배우자·아이에게 이어집니다.

- **청약**: 통장 가입 → 가점 정리 → 접수 → 당첨/탈락 → 계약 → 이사 날(가족과 밤새 정리 / 업체에 맡기기)
- **적금**: 자동이체 → 2년 만기 → 투자·여행·부모님 선물
- **주식**: 소액 시작 → 장이 흔들릴 때 버티기/손절/추매 → 결산(수익) 또는 부부 갈등
- **부동산**: 지인의 땅 이야기 → 서류 확인 후 투자(성공) / 한 방에 베팅(실패)
- **가족 연계**: 부부 통장, 아이 이름의 통장, 학원비 고지서, 집 넓히기, 보험 설계, 부업, 은퇴 자금 계산 — `requireFlags: 배우자 / 자녀`로 이어집니다.

## 🪃 과거의 부메랑 (중·노년기 50~80세)

1~30대에 남긴 선택을 회수하는 이벤트 14개입니다. 카드에 `🪃 과거의 부메랑` 배지와 함께 **그 플래그를 남긴 가장 이른 선택**을 짚어 줍니다.

- 예: 9세에 축구부에 들어간 선택 → 65세 `우리 손자는 왼발잡이`(동네 감독의 코치 제안)
- 예: 어릴 적 그림 씨앗 → 65세 `서랍 속 그림`(동네 전시·손주에게 물려주기), 단짝 → 50세 `오래된 친구의 제안`(동업)
- 연출: `🪃 9세 4개월차의 선택이 돌아왔습니다` + `‘축구부에 들어간다’` + 그 이벤트의 한 줄 설명(`boomerangNote`).
- 엔진: `boomerang: true` + `callback: ['플래그', ...]`, 출처 조회는 `Life.boomerangOf(state, event)`.

## 졸업 결산 · 명예의 전당

각 학교의 마지막 달(12개월차) 턴을 마치고 다음 나이로 넘어가는 순간, **졸업 결산**이 열립니다.

| 나이 | 졸업식 |
| --- | --- |
| 7세 12개월차 | 🐥 유치원 졸업식 |
| 13세 12개월차 | 🎒 초등학교 졸업식 |
| 16세 12개월차 | 📐 중학교 졸업식 |
| 19세 12개월차 | 🎓 고등학교 졸업식 |
| 24세 12개월차 | 🏛️ 대학교 졸업식 |

졸업 결산 화면은 ① 학령기 요약(선택 수·기억 2건·특성) ② **그 시절의 나에게** 회고 편지 ③ **또래와 비교**
④ **여기서 졸업하고 명예의 전당에 등록하기** / **계속 살기(80세까지 도전)** 두 갈래로 이루어집니다.

- **능력치 비교**: 체력·멘탈·매력·호감도·역량·행운·재산과 종합 점수(7개 + 종합)를, 같은 시점에 졸업한 표본의 평균과 비교해
  차이(`+8`, `-3`)·백분위(`상위 14%`)·평균선이 있는 막대그래프로 보여줍니다.
  기준 분포는 `tools/refdist.js`가 1세 시작 120판 + 각 단계 입학 나이 140판씩을 무작위 선택으로 돌려 만든
  백분위표(`assets/refdist.js`)입니다(`node tools/refdist.js 120 140`).
- **명예의 전당**: 졸업 엔딩(5단계)과 80세 완주 기록이 `localStorage`(`lifeTurnSim.hall.v1`)에 쌓입니다.
  시작 화면 우상단 `🏆 명예의 전당`과 플레이 중 상단 `🏆 전당`에서 언제든 열 수 있고,
  단계별 탭 + 점수순 정렬, 내 기록 강조(금색 테두리)와 상단 고정 카드(내 최고 기록)가 있습니다.
  첫 진입에도 비교할 수 있도록 시뮬레이션에서 뽑은 가상 인물 기록 28건을 기본 시드로 넣었습니다(`assets/hall-seeds.js`).
- **회고 편지**: 실제 스탯 구간·플래그·`history`의 마일스톤을 조합해 8~10줄의 문장을 매 판 새로 만듭니다
  (`Life.recall(s, 'grad' | 'life')`). 80세 엔딩에서는 평생을 돌아보는 회고로 나옵니다.

## 💬 제안·제보 게시판

플레이어가 **이벤트 아이디어**와 **버그·오타**를 바로 올릴 수 있는 게시판입니다. 로그인 없이 쓰고, 글은 Supabase에 쌓입니다.

- **진입**: 시작 화면 상단 `💬 제안·제보`(명예의 전당 옆) · 플레이 화면 상단 바 `💬 제안·제보`. 390px 한 줄에 4개 버튼이 들어가도록 플레이 바 버튼은 압축 스타일(`.sb-actions .ghost-btn`), 379px 이하에서는 이름(`.sb-name`)을 접습니다.
- **두 탭**: `💡 이벤트 제안` · `🐛 버그·오타 제보`. 정렬은 `최신순` / `공감순`.
- **글 작성**
  - 제안: 나이대(1~7·8~13·14~19·20~24·25~34·35세~·전체) + 제목(40자) + 상황·선택지 아이디어(600자) + 닉네임(선택)
  - 제보: **발생 위치·나이를 지금 플레이 중인 나이·개월차·사건 제목으로 자동 채움**(예: `14세 · 3개월차 · 「전학 첫날」`) + 내용 + 닉네임
  - 닉네임 기본값은 지금 플레이 중인 이름, 비우면 `익명`.
  - 검증: 빈 글·5자 미만·40/600자 초과 차단, **20초에 1건 · 하루 5건** 제한과 같은 글 재전송 차단(`localStorage`).
- **목록 · 👍 공감**: 카드마다 상태 배지(`접수됨`/`반영됨`/`수정됨`), 나이대, 작성 시각, 작성자, `👍 공감 n`. 공감은 기기별 1회(`localStorage` `lifeTurnSim.feedback.likes.v1`)이며 두 번째 누름은 `이미 공감한 글이에요`로 막힙니다. 4줄을 넘는 글은 카드를 눌러 펼칩니다.
- **저장**: Supabase 프로젝트 `zdcdvjlssncsawpqsjwe`(릴스핀과 공용)의 `public.life_sim_feedback` 테이블. 스키마·RLS·공감 RPC는 `supabase/life_sim_feedback.sql`(다시 실행해도 안전).
  - 공개 `SELECT` · 공개 `INSERT`(단 `likes=0`·`status='open'`·제목 2~80자·본문 5~1200자·닉네임 1~12자만 통과), `UPDATE`/`DELETE` 정책 없음.
  - 공감은 `increment_life_sim_feedback_like(row_id)` **security definer** RPC로만 +1 — 앱에서 `likes`를 직접 조작할 수 없습니다.
  - 운영자는 대시보드에서 `status`를 `open → applied / fixed`로 바꿔 배지를 갱신합니다.
- **오프라인**: 목록을 못 불러오면 `다시 불러오기` 버튼과 안내 문구를 보여 주고, 작성 중이던 글은 지우지 않습니다.

## 스탯

일곱 가지입니다(상단 HUD에 이 순서로 한 줄). 앞의 여섯 개는 0~100 게이지, 재산만 만원 단위 눈금입니다.

| 스탯 | 의미 |
| --- | --- |
| 체력 | 몸 상태. 나이가 들면 자연히 줄어듭니다. |
| 멘탈 | 정신력. 낮아지면 번아웃 이벤트가 발생합니다. |
| 매력 | 첫인상·분위기. 연애·발표·면접에 영향. |
| 호감도 | 주변 사람들과의 관계. |
| 역량 🧠 | 배우고 익혀 풀어내는 힘. 공부·시험·코딩·자격증·승진 심사에 영향(예: 고3 합격 발표 `tn_h50`은 멘탈과 역량이 절반씩). |
| 행운 🍀 | 맡겨 보는 몫. 복권·추첨·청약·투자·소개팅 같은 승부와 미니 승부 확률에 영향. |
| 재산 | 만원 단위. 마이너스(빚)도 가능합니다. |

### 역량·행운 규칙 (2026-11-18 추가)

- **역량**은 나이가 들수록 높은 값에서 출발합니다(1세 44 → 35세 시작 64). 공부·시험·코딩·프로젝트·자격증·승진처럼 배우고 풀어내는 선택에서 오르고, 그 선택은 대개 체력이나 멘탈을 조금 내줍니다.
- **행운**은 출발점이 어디든 50 근처입니다. 복권·뽑기·추첨·청약·투자·소개팅처럼 결과를 맡기는 선택에서 오르내리고, **생일마다 ±3 정도 흔들리며 50 쪽으로 조금씩 당겨집니다**(`applyLuckDrift`) — 그래서 사람마다 운의 폭이 다릅니다.
- **미니 승부에 반영**: `Life.luckBias(stats)`가 행운 50을 기준으로 승률을 **-25%p ~ +25%p** 밀어 줍니다(행운 100 → 75%, 0 → 25%). 동전·가위바위보·주사위·카드 하이로우가 이 값을 쓰고, 미니 승부 화면 하단에 `🍀 행운 62 이 승률에 반영됩니다`로 표시합니다.
- **기존 이벤트에도 연결**: `assets/events/zz-ability.js`가 로드 마지막에 주제(공부·시험·코딩·자격증 / 복권·뽑기·청약·투자·소개팅)에 맞는 기존 선택지 하나에 역량 또는 행운 +1~+2를 얹습니다. 이벤트 2,185개 가운데 역량 202개·행운 45개 선택지가 두 능력치를 움직입니다(그중 자동 연결이 역량 155·행운 8).
- **엔딩**: 역량 90 이상이면 `🧠 머리로 길을 만든 사람`, 행운 90 이상이면 `🍀 행운을 끝까지 들고 간 사람`, 행운 22 이하면 `🌧️ 운이 비켜 갈 때 버틴 사람` 갈래가 붙고, 회고 편지에 머리와 운을 다루는 한 줄이 들어갑니다.
- **저장 호환**: 저장본 버전 v4. 역량·행운이 없던 v1~v3 저장본은 `migrate()`가 50으로 채워 그대로 이어집니다(`stats`·`undo.stats`·`grad.stats` 모두).
- 검증: `node test/stats.js` (41항목) — 정의·프리셋·클램프·최고치 유지·저장 호환·결산 행·전당 기록·입시 합격선·행운 보정·전 연령대 이벤트.

### 밸런스 규칙 (2026-11-18 조정)

- 시작 스탯은 **50~60대**. 한 선택지의 변화는 **±1~±3**(극적인 대형 이벤트만 ±4~±5)입니다.
- **매달 스탯이 저절로 줄지 않습니다.** 예전의 `생활 소모(applyDrift)`는 제거했습니다 — 아무 선택도 하지 않았는데 달이 바뀌며 스탯이 빠지는 게 억울하다는 제보가 있었습니다.
- 대신 두 가지로 100에 붙지 않게 합니다.
  - **고수준 체감**: 80 이상이면 같은 +3도 0.8배, 88 이상 0.5배, 95 이상 0.25배로 오릅니다.
  - **최고치 유지**: 88을 넘긴 스탯만 달마다 아주 조금씩 88 쪽으로 내려갑니다(한 달 최대 1.4). 보통 범위(88 미만)는 그대로입니다.
- **생일 노화**: 45세부터 해가 바뀌는 달에 체력(62세부터 매력, 72세부터 멘탈)이 1씩 줄어듭니다.
- 그래서 **100을 찍기는 거의 불가능하고, 88~96 사이에서 선택으로 오르내립니다.**
- 스탯 분포가 바뀌었으므로 졸업 결산의 또래 비교 기준(`assets/refdist.js`)과 전당 시드(`assets/hall-seeds.js`)를 `node tools/refdist.js 120 140`로 다시 뽑았습니다.
- 검증: `node test/sim.js`의 `스탯 밸런스` 절 — 세대별 평균/최고, 100 도달 비율, 3턴 만의 100 도달 여부.

### 진로 갈래 · 결과 선택지 규칙 (2026-11-18)

- **진로 갈래는 하나만**: `진로_예술·체육·공학·의학·인문·교육·미디어·창업` 중 하나만 서고, 새 갈래를 고르면 나머지는 `false`가 됩니다(`LifeTracks.exclusive`). 체육 특기생이 어느새 예술 특기생이 되던 문제를 막습니다.
- 갈래를 정하는 이벤트(`tn_m20`·`tn_m32` 등)는 `when: LifeTracks.noTrack`으로 한 번만 뜨고, 예고·체육고 진학생은 별도 입학 이벤트(`tn_h90`·`tn_h91`)를 받습니다 — 특목고·자사고 입학 선택지(`high_enter`)는 숨김.
- **결과를 고르는 선택지는 두지 않습니다**: 시험·입시·면허 결과는 스탯과 그동안의 습관 플래그로 정해지고(예: `tn_h50` 합격 발표 — 멘탈·체력·성실함·성적 상승 등), 선택지는 ‘어떻게 받아들이는가’만 가릅니다. `set`·`effects`·`result`에 함수를 쓸 수 있습니다.

## 이벤트 추가하기

생애주기 모듈(`assets/events/*.js`)에 `X(...)` 한 줄로 추가하면 엔진이 자동으로 집어 갑니다.

```js
// X(stage, id, 나이(또는 [최소,최대]), 장소, 제목, 상황, 선택지[, 옵션])
X('work', 'my_event', [28, 30], '회의실', '제목', '상황 설명', [
  ['선택지 A', '결과 스토리', { mental: 2, asset: -1 }],          // 효과
  ['선택지 B', '결과 스토리', { social: 2 }, { 야근러: true }]     // 효과 + 플래그
]);

// 마일스톤(특정 나이·개월차 고정) 예
X('work', 'my_milestone', 28, '은행', '청약통장', '설명', [
  ['가입한다', '결과', { asset: -1 }],
  ['미룬다', '결과', { mental: 1 }]
], { at: [28, 4], milestone: true });

// 조건 분기 예 — 앞선 선택(플래그)이 있어야만 열리고, 스탯에 따라 확률이 달라진다
X('work', 'my_branch', [27, 34], '작업실', '작업실 임대', '설명', [
  ['얻는다', '결과', { mental: 3, asset: -300 }, { 작품활동: true }],
  ['집에서 계속한다', '결과', { mental: 1 }]
], { requireFlags: '예술가_길', minStat: { mental: 45 }, weight: function (s) { return s.flags.전시회 ? 4 : 2; } });

// 인생의 갈림길 — 같은 달의 다른 마일스톤보다 먼저 제시된다
X('college', 'my_fork', 20, '운동장', '동아리 선택', '설명', [
  ['가입한다', '결과', { hp: 3 }, { 축구부: true }],
  ['관중으로 남는다', '결과', { social: 2 }]
], { at: [20, 4], milestone: true, fork: true });
```

- `stage`: `infancy | elementary | middle | high | college | work | family | midlife | senior | any`
- **나이는 반드시 적습니다.** 그 나이 밖에서는 후보에서 아예 빠지므로 고증 오류가 나지 않습니다.
- 선택지는 2~4개, 효과는 `±1~±3`(재산은 만원 단위), `queue`로 다음 턴 후속 이벤트를 예약할 수 있습니다.
- `requireFlags`/`excludeFlags`/`minStat`/`maxStat`/`weight`/`fork`로 갈래를 만들고, `node test/branches.js`로 조건 위반 0건과 루트 도달을 확인하세요.
- 추가 후 `node tools/coverage.js`로 나이별 후보 수(13개 이상)와 `node tools/fallback.js`로 폴백 0회를 확인하세요.
