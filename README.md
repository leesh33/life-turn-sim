# 인생 턴제 시뮬레이션 — Life Turn Sim

30일 버튼 한 번, 한 살 한 살. 선택이 쌓여 인생이 되는 모바일 웹 턴제 시뮬레이션 프로토타입입니다.
아이폰 사파리(390×844) 기준으로 만들었고, 빌드 도구 없이 정적 파일만으로 동작합니다.

- 실서버: **https://life-turn-sim.vercel.app** (Vercel 프로젝트 `life-turn-sim`, 팀 leesh33)
- 저장소: https://github.com/leesh33/life-turn-sim
- 별도 백엔드 없음 · 진행 상황은 브라우저 `localStorage`에 자동 저장

## 플레이 방식

1. 시작 나이 7개 중 하나를 고릅니다.
   `1세(출산)` · `8세(초등학교 입학)` · `14세(중학교 입학)` · `17세(고등학교 입학)` · `20세(대학교 입학)` · `25세(취직)` · `35세(결혼)`
2. `[인생 시작하기]`를 누르면 30일 단위 턴이 시작됩니다.
3. 이벤트 카드에서 2~4개의 선택지 중 하나를 고르면 **결과 스토리 + 스탯 변화**가 즉시 표시됩니다.
4. `[다음 30일 진행하기 →]`를 누르면 30일이 지나고, 12턴(360일)마다 한 살이 됩니다.
5. 하단 `📖 인생 일지`에서 지나온 선택을 시간순으로 다시 볼 수 있고, `인생 요약`에서 언제든 칭호가 붙은 요약 카드를 볼 수 있습니다.
6. 80세가 지나면 엔딩(인생 요약)이 나옵니다.

## 스탯

| 스탯 | 의미 |
| --- | --- |
| 체력 | 몸 상태. 나이가 들면 자연히 줄어듭니다. |
| 멘탈 | 정신력. 낮아지면 번아웃 이벤트가 발생합니다. |
| 매력 | 첫인상·분위기. 연애·발표·면접에 영향. |
| 재산 | 만원 단위. 마이너스(빚)도 가능합니다. |
| 호감도 | 주변 사람들과의 관계. |

## 구현 메모

- **파일 구성**
  - `index.html` — 화면 골격(시작 / 플레이 / 엔딩) + 일지 시트
  - `assets/styles.css` — 카드형 모바일 UI, 안전영역(safe-area) 대응
  - `assets/engine.js` — 상태·이벤트 선택·스탯·저장·엔딩 칭호 생성
  - `assets/content.early.js` — 유아기(1~7세) · 초등학교(8~13세) 이벤트
  - `assets/content.mid.js` — 중학교(14~16) · 고등학교(17~19) · 대학교(20~24)
  - `assets/content.late.js` — 사회생활(25~34) · 가정(35~49) · 중년(50~64) · 노년(65~80) · 돌발 이벤트
  - `assets/content.extra.js` — 단계별 보강 이벤트(중학교·직장·중년·노년·비혼 루트·돌발)
  - `assets/app.js` — 렌더링/조작
- **이벤트 엔진**: 마일스톤(나이·일차 고정) → 앞선 선택이 예약한 후속 이벤트(`queue`) → 돌발 이벤트 → 해당 생애 단계의 미사용 이벤트 순으로 고릅니다. 한 번 쓴 이벤트는 다시 나오지 않고, 반복 이벤트는 5턴 쿨다운을 둡니다.
- **분기**: 선택이 플래그(`우렁찬_아기`, `대식가`, `문과/이과`, `특목고`, `재수생`, `군필`, `야근러`, `청약통장`, `청약당첨`, `결혼`, `자녀`, `직업` 등)를 남기고, 이후 이벤트의 등장 조건(`when`)과 결과 문구(`result` 함수)가 그 플래그를 읽습니다.
- **이벤트 수**: 152개(마일스톤·분기·반복 포함). 정적 검사와 80세까지 시뮬레이션은 `test/sim.js`, 비혼·번아웃 루트는 `test/routes.js`로 확인합니다.

## 로컬 실행

```bash
cd life-sim-web
python3 -m http.server 8811
# 브라우저에서 http://127.0.0.1:8811/
```

## 테스트

```bash
# 이벤트 정적 검사 + 7개 시작 나이 × 3회, 80세까지 헤드리스 시뮬레이션
node test/sim.js

# 실제 브라우저(390×844) 스크린샷 검증 (playwright 필요)
python3 test/shots.py --url http://127.0.0.1:8811/
python3 test/shots2.py --url http://127.0.0.1:8811/
```

## 이벤트 추가하기

`assets/content.*.js`에 아래 형태로 추가하면 엔진이 자동으로 집어 갑니다.

```js
{
  id: 'my_event',              // 고유 id
  stage: 'work',               // infancy|elementary|middle|high|college|work|family|midlife|senior|any
  at: [28, 90],                // (선택) 이 나이·일차에 반드시 — 없으면 해당 단계 풀에서 무작위
  place: '회의실',              // 카드 배지
  milestone: true,             // 마일스톤 배지
  when: function (s) { return s.flags.청약통장; },   // (선택) 등장 조건
  title: '제목',
  text: '상황 설명',
  choices: [
    {
      label: '선택지',
      result: '결과 스토리',       // 함수(function(s){...})도 가능
      effects: { mental: 4, asset: [-100, 100] },  // 배열이면 범위 랜덤
      set: { 청약당첨: true },     // 플래그
      queue: ['mortgage']          // 다음 턴에 이어질 이벤트 id
    }
  ]
}
```
